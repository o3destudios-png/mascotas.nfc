# O.3D.STORE — Fichas NFC

Esta carpeta está destinada exclusivamente a las fichas NFC de mascotas procedentes de O.3D.STORE.

## Separación de sistemas

- `GREY/` y `PETI-SUI/` pertenecen al sistema de protectoras y son registros de producción. No modificar.
- `O3DSTORE/` es el espacio independiente para nuevos clientes de O.3D.STORE.

Las fichas nuevas deberán crearse aquí sin modificar las fichas existentes de las protectoras.
